DemoLLM Documentation
=======================

A minimalistic LLM implementation for demonstration purposes.

This project demonstrates the core components of a modern generative AI system
in a simplified, understandable way. The implementation is intentionally small
and uses hardcoded weights for a handful of tokens.

.. note::
    This is a **demo-only** implementation. It is not meant for production use.
